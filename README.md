# Java Logic Building

A structured collection of Java problems focused on improving **logical thinking, problem-solving skills, and programming fundamentals** before starting Data Structures & Algorithms (DSA).

## Objectives

- Strengthen Java fundamentals
- Improve logical and problem-solving skills
- Practice writing clean and readable Java code
- Develop problem-solving patterns
- Build a strong foundation for DSA
- Document solutions and learning progress

## Topics Covered

1. **Conditional Thinking**
   - If-Else
   - Boolean Logic
   - Number Logic
   - Compound Conditions

2. **Looping & Patterns**
   - Loops
   - Number Problems
   - Mathematical Patterns
   - Pattern Printing

3. **Recursion**
   - Recursive Functions
   - Number Recursion
   - Pattern Recursion
   - String Recursion

4. **Basic Arrays**
   - Array Traversal
   - Searching & Counting
   - Transformation
   - Comparison

5. **Strings**
   - Character Analysis
   - Counting
   - Reversal
   - Palindromes
   - Word Manipulation

6. **Mixed Logical Challenges**
   - Number + Logic
   - String + Logic
   - Array + Loops
   - Applied Logical Problems
